# Lab 9: Implement K-Means, Agglomerative Hierarchical Clustering, and DBSCAN Using Python

## Files
- `sample_points.csv`: dataset of 2D points used for clustering.
- `Clustering_Algorithms.ipynb`: notebook implementation for K-Means, Agglomerative Clustering, and DBSCAN.

## Dataset
A synthetic 2D point dataset with several natural clusters. This dataset is intentionally not football-related and is safe to use as a unique topic.

## How to use
1. Open Jupyter Notebook.
2. Load `Clustering_Algorithms.ipynb`.
3. Run all cells.
4. Observe clustering outputs for K-Means, Agglomerative Hierarchical, and DBSCAN.

## Notes
- The notebook includes a manual K-Means implementation.
- Agglomerative clustering is visualized with a dendrogram.
- DBSCAN is implemented manually to identify core, border, and noise points.
